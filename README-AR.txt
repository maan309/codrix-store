SUBX — النسخة المعاد تصميمها (2026)
====================================

الملفات:
  index.html
  css/style.css
  js/app.js
  assets/subx-brand.webp  (شعار SUBX الأصلي، مقصوص لعرض أفضل)
  assets/subx-mark.webp   (جزء الشعار للعنوان والأيقونة)
  uploads/logo.jpg       (نسختك الأصلية من شعار الموقع)

مهم جدًا: أضف بنفسك ملف تطبيقك الأصلي إلى المسار:
  uploads/app-debug.apk

لم أضمّن APK في الحزمة لأن الملف موجود عندك على GitHub ولم يتم إرساله هنا.
زر التحميل يشير فعليًا إلى uploads/app-debug.apk.

خطوات النشر على GitHub Pages:
1) فك ضغط الحزمة.
2) انسخ محتويات SUBX-REDESIGN إلى جذر مستودع الموقع (وليس كمجلد فرعي).
3) احتفظ بملف uploads/app-debug.apk الموجود في المستودع، أو ارفعه إذا لم يعد موجودًا.
4) Commit ثم انتظر تحديث Pages وأعد تحميل الصفحة (Ctrl+Shift+R).
5) اختبر التحميل على جوالك.

ملحوظات:
- التصميم متجاوب من 320px وحتى شاشات سطح المكتب.
- حركات الانتقال تحترم تفضيل نظام التشغيل لتقليل الحركة.
- نموذج التواصل لا يرسل الرسائل لخادم؛ يفتح تطبيق البريد برسالة جاهزة.
- واجهة الهاتف في قسم أموالي رسم توضيحي فقط، وليست لقطة فعلية للتطبيق.
- الملف app-debug.apk إصدار تطوير؛ للتوزيع الواسع يُفضل APK إصدار Release موقّع.
- الخط الجميل يأتي من Google Fonts، ولديه بدائل محلية إذا تعذر الوصول إليه.
- استضافة GitHub Pages لا تشغّل خادم بريد، لكن روابط mailto تعمل.
- إذا كان APK كبيرًا جدًا، قد تحتاج استخدام GitHub Releases ووصلة تحميل خارجية.
