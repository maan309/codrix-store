للمطور

كيف تضيف تطبيقاتك؟

إضافة تطبيق جديد أمر بسيط جداً — فقط عدّل ملف JavaScript

1

ضع ملف APK في مجلد uploads/

انسخ ملف APK الخاص بتطبيقك إلى المجلد:

codrix-store/uploads/myapp-v1.0.apk

أو استخدم رابط GitHub Release مباشر بدلاً من ذلك.

2

افتح ملف js/app.js وعدّل المصفوفة

أضف بيانات تطبيقك داخل MY_APPS:

{ id: 'app-1', name: 'اسم تطبيقك', version: '1.0.0', size: '25 MB', category: 'أدوات', desc: 'وصف مختصر للتطبيق...', icon: null, iconEmoji: '📱', iconBg: 'linear-gradient(135deg,#1e3a8a,#3b82f6)', downloads: 0, rating: 5.0, date: Date.now(), fileName: 'myapp-v1.0.apk', fileUrl: 'uploads/myapp-v1.0.apk', }
3

احفظ وافتح الموقع

سيظهر تطبيقك فوراً في الشبكة مع زر تحميل مباشر. كرر الخطوة لكل تطبيق إضافي.
